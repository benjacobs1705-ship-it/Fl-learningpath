# FL Studio Kick Builder & Learning Path

An interactive learning tool for designing original uptempo hardcore kicks for FL Studio.

## Planned features
- Parametric kick synth: click, punch, body, tail and pitch envelope
- Distortion and waveshaping with waveform and spectrum views
- Creative transformations into risers, screeches and impacts
- Dutch lessons, A/B comparisons and hands-on exercises
- 24-bit PCM WAV export (44.1/48 kHz) for FL Studio

## Development
This repository is currently a **project scaffold**, not yet a working synthesizer. See [AGENTS.md](AGENTS.md) for Codex implementation requirements and [docs/ROADMAP.md](docs/ROADMAP.md) for milestones.
